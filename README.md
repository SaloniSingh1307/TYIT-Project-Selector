# TYIT Project Selector

A role-based web application designed to streamline the process of selecting and allocating final-year IT projects for students

## Features

- Student Registration & Login System
- Admin Dashboard for project approval/rejection
-  Students can submit up to 3 project preferences per attempt
-  Maximum 5 attempts per student
-  AI-based project recommendation system
-  CSV export functionality for admin
-  Structured project database (150+ projects)

---

## Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Backend:Python Flask  
- Database: SQL Server (SSMS)

---

##  How It Works

1. Students register and log in to the system  
2. Submit 3 project preferences per attempt  
3. Admin reviews and either:
   - Approves one project
   - Rejects all  
4. Students can retry up to 5 times  
5. AI recommends and auto-approves one project  
6. Admin can export all data in CSV format
