# Smart Project Allocation System (TYIT Project Selector)

## Overview

Smart Project Allocation System is a role-based web application developed to streamline the final-year IT project selection and allocation process. The system enables students to submit project preferences while providing administrators with tools to manage approvals, allocations, and project records efficiently.

---

## Features

### Student Module

* Student Registration and Login
* Submit up to 3 project preferences per attempt
* Maximum 5 attempts per student
* View project recommendations based on selected technologies
* Track project allocation status

### Admin Module

* Secure Admin Login
* Review project submissions
* Approve or reject project requests
* Manage project records
* Export project allocation data to CSV

### System Features

* Role-based Authentication
* Project Recommendation System
* Database-driven Application
* CSV Export Functionality
* Structured Project Repository with 150+ Projects

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/SaloniSingh1307/TYIT-Project-Selector.git
```

### 2. Navigate to Project Directory

```bash
cd TYIT-Project-Selector
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure Database

* Create the SQL Server database.
* Restore/import the provided database schema.
* Update database connection settings in the Flask application.

### 7. Run the Application

```bash
python app.py
```

### 8. Open in Browser

```text
http://localhost:5000
```
